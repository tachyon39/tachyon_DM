1 AI 설정

이 브라우저에 키 저장 (공용 기기에서는 끄세요)
키를 넣으면 그 회사의 중간급 최신 모델을 자동으로 골라요. 직접 바꿀 수도 있어요.

2 대화 넣기

여기를 눌러 파일 선택 · 또는 끌어다 놓기
.txt · .csv · .zip (카카오톡 / WhatsApp 내보내기)
또는 대화를 직접 붙여넣기
대화 내보내는 방법
  • 카카오톡 모바일: 채팅방 → 우측 상단 ≡ → 설정(톱니바퀴) → 대화 내용 내보내기 → 텍스트만 보내기
  • 카카오톡 PC: 채팅방 메뉴 → 대화 내용 → 대화 내보내기 (.txt)
  • WhatsApp: 채팅 → 더보기 → 대화 내보내기 → 미디어 없이
