2 대화 넣기

여기를 눌러 파일 선택 · 또는 끌어다 놓기
카카오톡 .txt · WhatsApp .txt/.zip · 인스타그램/메신저 .json/.zip (여러 파일 한 번에 가능)
📱 인스타 DM 등은 화면 녹화 영상이나 스크린샷 여러 장도 돼요 (1단계 API 키 필요)

🎞 화면 녹화 읽기

또는 대화를 직접 붙여넣기
대화 내보내는 방법
  • 카카오톡 모바일: 채팅방 → 우측 상단 ≡ → 설정(톱니바퀴) → 대화 내용 내보내기 → 텍스트만 보내기
  • 카카오톡 PC: 채팅방 메뉴 → 대화 내용 → 대화 내보내기 (.txt)
  • WhatsApp: 채팅 → 더보기 → 대화 내보내기 → 미디어 없이
  • 인스타그램 DM: 프로필 → ≡ → 계정 센터 → 내 정보 및 권한 → 내 정보 다운로드 → 정보 다운로드 → 일부 정보 선택 → 메시지만 체크 → 기기로 다운로드 → 형식 JSON, 미디어 화질 낮음 → 파일 만들기. 준비되면(몇 분~몇 시간) 받은 .zip을 그대로 올리세요. 메뉴 이름은 앱 버전에 따라 조금 다를 수 있어요.
  • 화면 녹화 (인스타·라인·아이메시지 등 아무 앱): 화면 녹화를 켜고, 대화방 맨 위(또는 맨 아래)에서 시작해 천천히, 한 화면씩 멈췄다가 스크롤하세요. 너무 빨리 넘기면 글자가 흐려서 못 읽어요. 몇백 개 메시지까지 권장해요.
  • 페이스북 메신저: 같은 계정 센터의 ‘내 정보 다운로드’에서 같은 방식(JSON)으로 받으면 돼요.
